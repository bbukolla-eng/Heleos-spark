# Decision records

Material decisions that change how Heleos-spark is built or governed are
recorded here, one file per decision, named `YYYY-MM-DD-<slug>.md`.

Each record states the question, the options considered (a council
deliberation transcript or summary when one was run), the decision, who made
it, and the date. Design-level changes still require the owner's recorded
approval per section 16 of the foundation design spec.
