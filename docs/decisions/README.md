# Decision records


Material decisions that change how Heleos-spark is built or governed are recorded here, one file per decision, named `YYYY-MM-DD-<slug>.md`.


Each record states the question, the options considered (with the run record of any `judge-panel` deliberation), the evidence relied on, the decision, who made it, and the date. Design-level changes still require the owner's recorded approval per section 16 of the foundation design spec. Only the owner writes here; workflows and sessions produce drafts under `docs/roadmap/decision-drafts.md`.
